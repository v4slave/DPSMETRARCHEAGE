## Все ветки

`build_catalog.py` скачивает XML веток 1–14 и соответствующие листы:
`https://archeage.ru/static/aa.mail.ru/calculator/skills/6/skills_{branch}.xml?v=2`
`https://aa.cdn.gmru.net/static/aa.mail.ru/img/main/content/calculator/active_skills/data_clid_{branch}.png?5`

`skills.tsv` содержит 414 записей, 382 уникальных ID умений из 14 веток.
Варианты Эфе'рунд пока используют базовую иконку способности; если для ID нет
подтверждённой записи, он сохраняется под ID со знаком вопроса.

## Названия NPC

Имена типов NPC сверены по публичным карточкам ArcheAge Codex:
https://archeagecodex.com/ru/npc/7512/ — Легкий манекен.
https://archeagecodex.com/ru/npc/8029/ — Мертвый всадник.

Новые типы NPC разрешаются по такой же публичной карточке в фоновом потоке
и сохраняются в `npc-names.tsv`. Имена игроков читаются из пакетов появления;
запросы с именами игроков или ID объектов на сайт не отправляются.
