# Интерфейс ArcheAge DPS

Игрок смотрит личный урон во время боя, сравнивает цели и вклад умений.
Частое действие — выбор цели; данные должны читаться без переключения вкладок.
Концепция: functional-clarity, плотный игровой инструмент с бронзовым акцентом.
Ограничения: Windows Forms/.NET Framework, минимум 840×570, без управления окнами пользователя.

- Segoe UI: заголовок 16, число DPS 25, таблица 10, подписи 8–9.
- Шаг отступов 4/8/12/16/24; поля и числа выровнены по общей сетке.
- Фон #12151B, поверхность #1A1E26, текст #EFEBE0, вторичный #A7ADB5, акцент #D8B573.
- Умения имеют реальные иконки; доля урона дополнена полосой в той же строке.
- Диагностические пакеты/ошибки/технические пояснения убраны с экрана.
- QA: рендер собственных контролов в PNG при 980 и 840 пикселях, без показа окна.
