# ArcheAge DPS

Запуск: `dist/ArcheAgeDPS.exe`. Это один файл приложения со встроенной иконкой
ArcheAge, базами названий и изображениями. Можно перенести только EXE в другую
папку. Python, компилятор и исходники для запуска не нужны.

При первом запуске данные извлекаются в `%LOCALAPPDATA%\ArcheAgeDPS`.
Там же хранятся настройки, записи трафика и журналы ошибок. Для чтения трафика
нужен установленный Npcap; он уже использовался на этом компьютере.

## Интерфейс

- Слева выбирается источник урона, справа — все цели либо конкретная цель.
- Свой персонаж выбирается автоматически по личному пакету входа и его связи
  с игровым объектом. Запустите meter до входа персонажем; если игра уже открыта,
  вернитесь в выбор персонажа и войдите снова. При смене персонажа замер очищается.
  До получения пакета входа можно выбрать источник вручную.
- Общий DPS остаётся виден при выборе отдельной цели.
- Вкладки: умения, все цели, последние попадания и сравнение.
- «Сравнение» показывает полосы урона всех записанных источников по убыванию,
  суммы и доли в процентах. Выбор источника не ограничивает сравнение;
  фильтр цели позволяет сравнить вклад по одному противнику. NPC и неизвестные
  источники тоже отображаются с именем или ID. Длина полосы считается относительно лидера,
  процент — от суммарного урона по выбранной цели.
- Новый замер очищает текущую статистику; записи на диске сохраняются.
- Диагностический блок с пакетами и ошибками удалён с экрана.
- Тёмная тема, бронзовый акцент, полосы доли урона и оригинальные иконки.

DPS считается за период между первым и последним событием источника.
Фильтры целей и умений используют тот же период. Паузы внутри периода учитываются.

## Что проверено

- Сборка запускается из отдельной папки, в которой есть только один EXE.
- Скрытые рендеры при ширине 980 и 840: `qa/release-980.png`, `qa/release-840.png`.
  Окна пользователя и его экран при проверке не использовались.
- Контраст обычного текста 14.02:1, вторичного 7.39:1, акцента 7.69:1.
- Тесты фильтров, сумм, группировки умений, справочников NPC и эффектов проходят.
- На записи проверена атрибуция глайдера: 25000 начального огня и 5000 ожога
  относятся к игроку через объект глайдера; исходное поле сохраняется в CSV.
- На записи входа Dor проверены автоопределение, связь с объектом 112854
  и шесть исходящих событий урона. Список персонажей аккаунта не выбирает источник.

## Ограничения

Экспериментальный декодер не гарантирует полноту всех событий текущего клиента.
Автоопределение требует записи входа персонажа и поддерживает наблюдённый формат
RU-клиента. Ник и ID владельца не включаются в EXE. Для имени цели нужно
получить сообщение её появления: если цель
стояла рядом до запуска, отойдите за дистанцию видимости и вернитесь.

База содержит все опубликованные списки Codex: 17866 NPC и 31014 эффектов,
а также умения всех 14 веток и дополнительные наблюдённые NPC-умения.
Новые публичные карточки уточняются по ID и кэшируются. Из game_pak извлечены
копии иконок; игровой архив не изменялся. Клиентская compact.sqlite зашифрована.

Текущая сессия записи ограничена 15 минутами и 128 МиБ. Это пока не бессрочный
монитор. При завершении записи отображается короткая пометка «Замер завершён».

## Разработка

`Build-Release.ps1` собирает `dist/ArcheAgeDPS.exe` с упакованными ресурсами.
`Start-Meter.ps1` пересобирает и открывает этот же единый EXE.
Исходники протокола: `Meter.cs`, `Capture.cs`; интерфейс: `Dashboard.cs`, `Theme.cs`;
запуск и упаковка: `Startup.cs`, `AppPaths.cs`, `build_release.py`.

Происхождение данных и иконок: `assets/SOURCES.md`. Историческая сверка чата:
`validation.json`. Дизайн: `DESIGN.md`.

## Установщик для Windows 10/11 x64

Запустите `dist/ArcheAgeDPS-Setup.exe`. Это пошаговый мастер Inno Setup на русском:
выбор папки, ярлык рабочего стола, подтверждение параметров, прогресс и запуск
после завершения. Ярлыки приложения и удаления доступны в меню «Пуск».
Папка по умолчанию — `%LOCALAPPDATA%\Programs\ArcheAgeDPS`;
можно выбрать другую папку, доступную текущему пользователю.
Установка выполняется для текущего пользователя. Запись для удаления появляется
в «Установленных приложениях» Windows. Приложение встроено в установщик;
Python и инструменты разработки на целевом компьютере не нужны.

При отсутствии Npcap мастер скачивает версию 1.90 с
https://npcap.com/dist/npcap-1.90.exe, проверяет доверенную цифровую подпись
издателя и открывает официальный мастер с запросом прав администратора.
Пройдите мастер Npcap; бесплатная версия не поддерживает тихую установку.
При запросе перезагрузки выполните её перед запуском meter.
Уже установленный Npcap повторно не скачивается.
Ошибка загрузки или отмена Npcap останавливает установку до копирования приложения.

Повторный запуск обновляет приложение в ранее выбранной папке.
Перед обновлением закройте meter. Для удаления используйте настройки Windows
или ярлык «Удалить ArcheAge DPS». Настройки и записи в
`%LOCALAPPDATA%\ArcheAgeDPS` сохраняются. Npcap удаляется отдельно.

Сборка: `./Build-Installer.ps1` или `./Build-Installer.ps1 -SkipAppBuild`.
Нужен Inno Setup 6.7+; путь к ISCC.exe можно передать через `-CompilerPath`.
Сценарий: `ArcheAgeDPS.iss`, проверка драйвера: `installer/Verify-Npcap.ps1`.
Тест установки/обновления/удаления: `installer/Test-Installer.ps1`.
Тест требует установленный Npcap и отсутствующую установленную копию meter;
использует тестовую папку внутри `build/setup-qa` без ярлыков.
Для тихой установки Npcap должен быть установлен заранее.
Npcap не включается в распространяемый EXE; условия: https://npcap.com/#license .
